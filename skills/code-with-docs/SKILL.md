# Code With Docs

Use this skill only when the developer explicitly invokes $code-with-docs.

## Purpose

This skill establishes a documentation-first development workflow. It will help clarify requirements, organize development documentation, obtain approval, and implement changes against the approved documentation.

## Planned workflow

1. Clarify the requirements and success criteria.
2. Produce or update the development documentation.
3. Confirm the documentation before implementation.
4. Implement the approved change without silently changing scope.
5. Verify that the implementation matches the documentation.

## Scope boundary

This file is the initial skill entrypoint. Detailed questioning rules, document templates, approval gates, and implementation procedures will be designed in a later iteration.
